> 环境说明:本机无图像生成能力、Open Design 守护进程未运行,故以**文字设计规格 + HTML 预览**代替
> 图像方向稿。三个方向共用同一结构骨架(48vp rail + 终端画布 + 右侧 inspector overlay,见
> `requirements.md` 不可动约束),只在**配色、签名元素、材质、字体角色、微动效语法**上分化。

## 方向一:纸间 Inkfolio — 浅色编辑室

**个性**:编辑室/书房。终端像一页稿纸,UI 像排版注记。反类型(终端产品几乎全是深色),
安静、笃定、有纸质温度。差异化最强。

**配色 token**
- 终端/应用基底:纸 `#F2EFE7`;rail:`#EAE6DB`;inspector 面板:`#FBFAF5`;选中/浮起行:`#E4DFD2`
- 主文字:墨 `#1C1A15`;次文字:`#6E675A`;发丝线:`#D8D2C2`
- 签名色:朱砂 `#B23B2E`(印章红)——只出现在状态印、选中墨线、主按钮
- 语义小字:成功 `#3E7C4F`,失败 `#B23B2E`(与朱砂同色,靠图标/文字区分)
- 终端画布:纸面浅底,墨色正文 `#23211B`,ANSI 调色板整体降饱和「纸化」

**签名元素:朱砂印**
- tab 标题前一枚 8vp 方印(2vp 圆角)。状态映射:已连接=实心印;连接中=印点慢闪
  (opacity 0.35↔1,~2.4s,状态门控);失败=空心描边印;完成未读=印+右侧小圆点;选中=印不动,
  标题下加 1.5vp 墨线。
- 连接成功动效:「落印」——印 translateY(-1vp→0)+ opacity,180ms decel,无回弹,像盖章。

**字体角色**:chrome 中文/正文 sans regular/medium;**tab 标题、状态读数、设置读数用等宽**
(打字机/排印注记感);终端等宽。

**密度/材质**:中低密度,留白多;层级靠纸面色差 + 发丝线,零投影或仅菜单一层极浅影。

**风险**:浅色终端需整套纸化调色板;夜间场景刺眼(后续配深色终端主题);评审风险最高但也最独特。

## 方向二:冷仪 Coldframe — 深色仪器面板

**个性**:实验室仪器/航电面板。精确、冷静、读数化。工程气质延续 Ghostty 的「工具感」,
但语言完全换新——状态用**仪器读数**表达,不用任何「生命体征」隐喻。

**配色 token**
- 基底:蓝黑钢 `#0C1014`;rail:`#0A0D11`;面板:`#12171D`;选中行:`#182027`
- 主文字:`#C7D2DC`;次文字:`#77828E`;发丝线:`#232B34`
- 签名色:信号青 `#4EC9B0`——只出现在信号条、CONN 读数、主按钮
- 失败红 `#D3604F`;完成读数用主文字色不另设色
- 终端画布:同基底深色,ANSI 偏冷

**签名元素:信号条 + 状态读数**
- tab 左缘 2vp 竖向信号条(静态,无辉光) + 标题右侧 11vp 等宽读数:`CONN` / `···` / `FAIL` / `DONE`。
- 连接成功:「写入」——信号条 translateY(-100%→0) 250ms decel,像标尺注水,一次性。
- 连接中:读数 `···` 逐点步进(瞬时切换,不补间)或信号条半高明暗(状态门控)。
- 失败:条变红 + `FAIL`;完成未读:`DONE` 读数 + 标题提亮。
- 选中 tab:面板色微升 + 信号条全亮;非选中已连接:条 40% 亮度。

**字体角色**:读数/标签等宽(仪器感核心),中文标签与正文描述用 sans(CJK 无真等宽,混排需验证);
数字 tabular。

**密度/材质**:密度略高,信息读数化;零圆角或 2vp 小圆角;发丝线 + 面板色差分层,无影。

**风险**:全等宽标签的 CJK 混排观感;信号青在小字号读数上的对比度(#4EC9B0 on #0C1014 ≈ 7:1,达标);
「仪器感」过度会变繁琐——丝网印细节限制在读数与 hairline。

## 方向三:深场 Eventide — 饱和暗色 + 一线极光

**个性**:影院/深空。暗色但不死黑,带紫蓝底色,安静有一层「场」。三个方向里最「氛围」的,
但氛围只许出现在一条线上。

**配色 token**
- 基底:深紫蓝 `#0B0B15`;rail:`#0A0A12`;面板:`#14141F`;选中行:`#1A1A28`
- 主文字:`#D4D4E4`;次文字:`#82829A`;发丝线:`#262636`
- 签名:极光渐变(靛 `#6E7BE0` → 青 `#46C2C8` → 紫 `#9B6ED8`)——**只出现在 1vp 宽的线、
  tab 底缘、主按钮描边**;永不填充大面积,永不流动循环
- 失败:光线褪为单色灰红 `#8A4A52`;语义小字同冷仪纪律
- 终端画布:同基底,ANSI 中性偏冷

**签名元素:一线光**
- tab 底缘 1vp 渐变光线。已连接=静态亮起;连接中=光线呼吸(opacity 0.3↔1,状态门控);
  连接成功=一次从左到右「点亮扫过」(clip translateX,300ms,一次性,不循环);
  失败=褪色灰红;完成未读=光线亮度提升一档;选中=面板色微升 + 光线全亮。
- 主按钮:描边渐变,填充深面板色,pressed opacity 0.82。

**字体角色**:sans 为主(chrome 全 sans),终端等宽;不用等宽 chrome。

**密度/材质**:中密度;层级靠面板色差 + 发丝线;菜单一层克制投影;圆角 4/6/8。

**风险**:渐变最易俗——硬约束:仅 1vp 宽线元素、静态、低亮度;与旧灯丝同为「线性签名」,
结构相似但配色/材质/动效语义全新,评审时需明说差异。

## 共用预览契约(三个 HTML 预览都必须满足)

- 单一自包含 `index.html`,零外部依赖(无 CDN、无网络字体)。字体栈:sans 用系统栈
  (`"HarmonyOS Sans","PingFang SC","Microsoft YaHei",sans-serif`);等宽
  (`ui-monospace,"JetBrains Mono",Menlo,Consolas,monospace`)。
- 主要评审视口 1440×900;960 宽度不崩(rail 紧凑、inspector 352px)。
- 必含场景:48px rail(左 4 个 tab,各呈 active+connected / connecting / failed / unread-complete
  四态;右 连接/设置/溢出三动作 + 系统窗控件占位);终端画布(tmux 风格真实内容,含中文输出,
  等宽 pre);右侧 inspector overlay(352px,segmented「终端/外观/连接」,设置行 label 左控件右,
  连接页含内联 retry/details);溢出菜单示意。
- 交互演示:点 tab → 终端内容**硬切**(无过渡);inspector 可开关(220ms opacity+translate);
  hover/pressed 态;页底加一条「预览演示控制条」(明确标注非产品 UI)用于循环连接状态、演示签名动效。
- 动效只用 CSS opacity/transform/color/background;禁 width/height/padding/font-size 过渡;
  CJK 文字禁 scale;无常驻循环(connecting 态循环需状态门控,切走即停)。
- 所有 UI 文案中文(终端/外观/连接/重试/详情等)。
