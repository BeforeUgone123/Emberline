Emberline —— 鸿蒙上的完整伪终端

Emberline 是一款 HarmonyOS 原生终端模拟器,终端内核源自知名开源终端 Ghostty 的终端引擎。它不是网页套壳,也不是简化的命令行玩具:从伪终端(PTY)到转义序列解析,再到逐格原生渲染,走的都是桌面级终端的完整链路。专为 HarmonyOS 平板与二合一设备设计,键盘、触控板、触屏三种形态都被认真对待——像桌面终端一样严肃,像移动应用一样顺手。

【完整的终端仿真】

vim、htop、tmux 在这里开箱即用,不需要任何妥协。

一、支持 256 色与真彩显示,现代命令行工具的配色原样呈现;
二、完整的 VT/xterm 兼容:应用光标键、括号粘贴、窗口标题、Shift+Tab 反向补全等桌面终端的标准能力一应俱全;
三、终端鼠标协议:在 tmux、vim 里开启鼠标模式后,触屏自动化身鼠标——轻点是点击,长按拖动可以直接拖 tmux 分栏调整大小,滑动就是滚轮;
四、远程复制直通:远端 tmux、vim 复制的内容可以直接写入本机剪贴板;
五、远端任务完成的终端提醒会桥接为系统通知,后台标签跑完任务会喊你回来。

【原生渲染,不掉帧】

渲染层用 C++ 原生实现:按脏行重绘、离屏缓冲复用、滚动位移直接搬运,大屏幕上刷长日志也不掉帧。触屏和触控板滚动做到逐像素跟手,松手带惯性;选择文字拖到屏幕边缘会自动滚动续选,跨屏长文本一次选完整。中文使用等宽字体渲染,任意字号下字距、光标、选区严格对齐,没有缺字。

【三种连接,一个入口】

本地 shell、SSH、WebSocket Agent 三种会话统一在多标签里管理。

面向 HarmonyOS 电脑「融合开发引擎」的 Linux 虚拟机,推荐使用 Agent 会话:在虚拟机里跑一个轻量代理,应用直连虚拟机的伪终端,零配置共享目录,断线按指数退避自动重连。后台连续任务与熄屏恢复须以发布真机矩阵为准。SSH/SFTP 当前是开发回退,在依赖升级和主机密钥校验完成前不得随正式版宣传或发布;本地 shell 是否可用取决于设备沙箱。

标签支持动态宽度、按住即拖的轨道内重排(邻居实时让位)、右键改名与关闭,还可以自定义每个标签的灯丝颜色。关闭标签不会打断远端 tmux 里正在跑的任务。

【物理键盘优先,触控不缺席】

外接键盘时它是桌面终端:Ctrl+Shift+C、Ctrl+V 负责复制粘贴,而 Ctrl+C 永远是中断信号,不会被剪贴板截胡。Tab、Esc、方向键与功能键统一经过原生按键编码器,屏幕上不叠加快捷键栏。触控负责滚动、选择、链接与中文输入,终端里可以正常输入中文。

【截图直达终端】

在任何地方截图,回到终端按 Ctrl+V——图片自动落盘,终端里粘出的是目标机器视角的可用路径:本地会话给本地路径,虚拟机会话走共享目录零上传,SSH 会话经 SFTP 送达远端。把截图丢给远端的命令行 AI 工具,就是一次粘贴的事。每个标签还可以单独设置粘贴视角,包括把图片经虚拟机中继转发到内网另一台机器。

【克制的自定义】

内置 458 套 Ghostty 主题,带真实色板预览;五款内置等宽字体,支持 ttf、otf 字体文件自由导入;背景图与亚克力模糊、光标三种形态可调。每个设置项下方都标注了对应的 Ghostty 配置键,熟悉桌面 Ghostty 的用户零学习成本。

界面上只有一种颜色会发光:标签底缘那根余烬铜灯丝——亮着,你的会话就活着。

【安全与隐私】

SSH 密码不落盘,仅在当次连接中使用;Agent 连接使用令牌鉴权,开发默认只适用于可信 VM 桥接网络,不得直接暴露到公网。连接配置只保存在本机。应用不采集、不上传任何用户数据。

【适合谁】

需要随时连回开发机、服务器的开发者与运维;在融合开发引擎 Linux 虚拟机里写代码的 HarmonyOS 开发者;以及任何希望在鸿蒙设备上拥有一个不打折扣的真正终端的人。

Emberline,为 HarmonyOS 而生的桌面级终端。
