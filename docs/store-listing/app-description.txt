Emberline —— 鸿蒙上的完整伪终端

Emberline 是一款 HarmonyOS 原生终端模拟器,终端内核源自知名开源终端 Ghostty 的终端引擎。它不是网页套壳,也不是简化的命令行玩具:从伪终端(PTY)到转义序列解析,再到逐格原生渲染,走的都是桌面级终端的完整链路。专为 HarmonyOS 平板与二合一设备设计,键盘、触控板、触屏三种形态都被认真对待——像桌面终端一样严肃,像移动应用一样顺手。

【完整的终端仿真】

vim、htop、tmux 在这里开箱即用,不需要任何妥协。

一、支持 256 色与真彩显示,现代命令行工具的配色原样呈现;
二、完整的 VT/xterm 兼容:应用光标键、括号粘贴、窗口标题、Shift+Tab 反向补全等桌面终端的标准能力一应俱全;
三、终端鼠标协议:在 tmux、vim 里开启鼠标模式后,触屏自动化身鼠标——轻点是点击,长按拖动可以直接拖 tmux 分栏调整大小,滑动就是滚轮;
四、远程复制直通:远端 tmux、vim 复制的内容可以直接写入本机剪贴板;
五、远端任务完成的终端提醒会桥接为系统通知,后台标签跑完任务会喊你回来。

【原生渲染,不掉帧】

渲染层用 C++ 原生实现:按脏行重绘、离屏缓冲复用、滚动位移直接搬运,大屏幕上刷长日志也不掉帧。触屏和触控板滚动做到逐像素跟手,松手带惯性;选择文字拖到屏幕边缘会自动滚动续选,跨屏长文本一次选完整。中文使用等宽字体渲染,任意字号下字距、光标、选区严格对齐,没有缺字。全屏、分屏与多窗口下的刷新路径都做过针对性修复。

【AI 工具的原生工位】

Codex、Claude Code 这类命令行 AI 工具原生跑在会话里:中文输出不乱码、不掉字,长任务在后台跑完会发系统通知,标签标为未读、标题提亮。配合 tmux 分栏与文件管理器,一块屏就是一整套工作流。

【连接:直连融合开发引擎虚拟机】

面向 HarmonyOS 电脑「融合开发引擎」(Fusion Development Engine)自带的 Linux 虚拟机:在虚拟机里跑一个轻量代理,应用经 WebSocket 直连它的伪终端,零配置共享目录,断线按指数退避自动重连,等待期间敲键即可立即重试。应用退到后台时会向系统申请任务保活,让长任务继续跑完并送出通知。设备沙箱允许时,也可以直接在本机开一个 shell。

【标签与多窗口】

标签是等分的浮动胶囊:按住拿起就能在轨道内重排、邻居实时让位,双击或右键改名,只剩一个标签时收敛成一行居中标题。右键还能把标签「拆分为新窗口」或「移动到窗口」——交接的是活着的会话本身,伪终端与连接全程不断开,远端 tmux 察觉不到自己换了窗口。关闭标签同样不会打断远端正在跑的任务。

【物理键盘优先,触控不缺席】

外接键盘时它是桌面终端:Ctrl+Shift+C、Ctrl+V 负责复制粘贴,而 Ctrl+C 永远是中断信号,不会被剪贴板截胡。Tab、Esc、方向键与功能键统一经过原生按键编码器,屏幕上不叠加快捷键栏,终端画面始终完整。触控负责滚动、选择、链接与中文输入,终端里可以正常输入中文。

【截图直达终端】

在任何地方截图,回到终端按 Ctrl+V——图片自动落盘,终端里粘出的是目标机器视角的可用路径:本地会话给本地路径,虚拟机会话走共享目录零上传。把截图丢给远端的命令行 AI 工具,就是一次粘贴的事。每个标签还可以单独设置粘贴视角,包括把图片经虚拟机中继转发到内网另一台机器。

【克制的自定义】

内置 458 套 Ghostty 主题,带真实色板预览;五款内置等宽字体,支持 ttf、otf 字体文件自由导入;背景图与亚克力模糊、光标三种形态可调。深色与浅色各配一套主题,可以跟随系统,也可以手动锁定其中一种。每个设置项下方都标注了对应的 Ghostty 配置键,熟悉桌面 Ghostty 的用户零学习成本。

界面上没有一处强调色。顶栏直接取终端的背景色,与网格浑然一体;文字、分隔线、悬浮面板都是前景色的不同透明度。换一套主题,变的是整个应用——它没有自己的颜色,你的主题是什么样,它就是什么样。标签上那颗中性小圆点是全部的状态语言:亮着,你的会话就活着。

【安全与隐私】

Agent 连接使用令牌鉴权,当前面向可信的虚拟机桥接网络;所有连接配置只保存在本机。应用不采集、不上传任何用户数据。

【适合谁】

在融合开发引擎 Linux 虚拟机里写代码的 HarmonyOS 开发者;习惯把命令行 AI 工具挂在终端里干活的人;以及任何希望在鸿蒙设备上拥有一个不打折扣的真正终端的人。

Emberline,为 HarmonyOS 而生的桌面级终端。
