# Emberline

**鸿蒙上的完整伪终端。**

---

Emberline 是一款 HarmonyOS 原生终端模拟器,内核移植自 [Ghostty](https://ghostty.org) 的终端引擎(libghostty-vt)。它不是 WebView 套壳,也不是简化的命令行玩具——从 PTY 到转义序列解析再到逐格渲染,走的都是桌面级终端的完整链路。

## 完整的终端仿真

- **真 PTY**:本地会话直接 fork 出带伪终端的 shell,进程组、信号、窗口尺寸变更(SIGWINCH)全部按 POSIX 语义处理;
- **完整 VT/xterm 兼容**:256 色与真彩、DECCKM 应用光标键、bracketed paste、OSC 窗口标题、Shift+Tab 反向补全,vim / htop / tmux 开箱即用;
- **鼠标协议**:tmux、vim 开启鼠标模式后,触屏自动化身鼠标——轻点是点击,长按拖动可以直接拖 tmux 分栏调整大小,滑动是滚轮;
- **OSC 52 远程复制**:远端 `tmux set-clipboard`、vim 插件可直接写入系统剪贴板;
- **C++ 原生渲染**:脏行级重绘 + 离屏缓冲,滚动带惯性,长输出不掉帧。

## 三种连接,一个入口

本地 shell、SSH(libssh2)、WebSocket Agent 三种会话统一在多标签里。启动自动连回上次的主机,断线按指数退避自动重连,关掉标签不会打断远端 tmux 里正在跑的任务。

## 为键盘和触屏同时设计

外接键盘时它是桌面终端:Ctrl+Shift+C / Ctrl+V 复制粘贴,而 Ctrl+C 永远是中断信号,不会被剪贴板截胡。纯触屏时呼出辅助键条:Esc、Tab、方向键,Ctrl / Alt 支持粘滞组合。

## 截图直达终端

在任何地方截图,回到终端 Ctrl+V——图片自动落盘,终端里粘出的是**目标机器视角的可用路径**:本地会话给本地路径,虚拟机会话走共享目录零上传,SSH 会话经 SFTP 送达远端 `/tmp`。把截图丢给远端的 AI CLI 工具,就是一次粘贴的事。

## 克制的自定义

458 套 Ghostty 主题带真色板预览,五款内置等宽字体(默认 Maple Mono NF CN,中文对齐无缺字)外加 ttf/otf 自由导入,背景图与亚克力模糊,光标三态。每个设置项下方都标着对应的 Ghostty 配置键——熟悉桌面 Ghostty 的人零学习成本。

界面只有一种颜色会发光:标签底缘那根**余烬铜灯丝**——亮着,你的会话就活着。
